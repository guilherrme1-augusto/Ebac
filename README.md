# Calculadora de IMC

Aplicação web simples que calcula o **Índice de Massa Corporal (IMC)** a partir do peso e da altura informados pelo usuário e exibe a classificação correspondente.

Projeto desenvolvido como exercício do curso (módulo 4).

## 📋 Sobre o projeto

O usuário digita seu peso (em kg) e altura (em metros), clica em **Calcular** e recebe:

- O valor do IMC com duas casas decimais.
- A classificação de acordo com as faixas da Organização Mundial da Saúde (OMS).

## 🧮 Faixas de classificação

| IMC             | Classificação    |
| --------------- | ---------------- |
| Abaixo de 18,5  | Abaixo do peso   |
| 18,5 a 24,9     | Peso normal      |
| 25,0 a 29,9     | Sobrepeso        |
| 30,0 ou mais    | Obesidade        |

> **Fórmula:** IMC = peso ÷ (altura × altura)

## 🚀 Como executar

Não é necessário instalar nada. Basta:

1. Clonar ou baixar este repositório.
2. Abrir o arquivo `atividadem4.html` no navegador.

```bash
git clone https://github.com/SEU-USUARIO/calculadora-imc.git
cd calculadora-imc
```

Depois é só abrir o `atividadem4.html` com um duplo clique.
